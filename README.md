# 📙 웹 소개
<br>
<h3>🔔 주요 기능 🔔</h3>
<br><br>
<li>블로그의 핵심기능인 글 작성, 수정, 삭제 기능을 비동기로 처리하였습니다.<br>
게시글을 분류할수있는 카테고리 생성 및 삭제 기능을 지원하였으며 카테고리별 동적 페이지라우팅을 구현하였습니다.<br>
무분별한 카테고리확장을 막기위해 최대5개 제한 로직을 프론트/백엔드에 적용하였습니다.<br>
사용자의 실수로 데이터가 영구 삭제되는 상황을 방지하기위해 카테고리,글 삭제 확인모달 레이어를 구현했습니다
</li>
<br><br>

<h3>🛠트러블슈팅</h3>
<br><br>
<li>프로젝트 초기 라이브러리사용을 위해 NuGet패키지관리자 화면에서 설치를 클릭하면 패키지관리자GUI가 먹통이 되는 현상이 발생하였습니다.<br>
패키지가 프로젝트 파일에 수동으로 반영되는 원리를 검색하여 알아내었고, dotnet CLI를 통해 프로젝트 디렉토리에 접근하여서 dotnet add package 명령어로 패키지를 수동 설치하여서 프로젝트 빌드를 정상적으로 성공시켰습니다.
</li>
<br><br>
